Expand description

Round count stays within the coordinator’s max_rounds bound and round_durations has exactly one entry per round.

The bound is deliberately max_rounds, not n_nodes: since the coordinator stopped marking targets permanently failed on transient edge failures, an unlucky failure pattern can legitimately exceed n_nodes rounds while the strategy retries alternate sources.
