Module fleet 

Source
Expand description

Fleet configuration types shared by all integrations.

These types map to the JSON produced by the Nix library’s mkFleet function: the core node/builder topology plus optional per-integration sub-configs (ansible, slurm, ray, skypilot). They lived in consortium-nix historically; they moved here so integration crates can depend on the configuration without depending on the nix deployment pipeline. consortium-nix::config re-exports this module.
