The reporting contract every integration satisfies.

Each integration crate returns its own report type from its top-level entry points (e.g. consortium_nix::DeployReport, or the core DAG executor’s [DagReport]). IntegrationReport is the common denominator the contract-test harness and higher-level tooling code against, so “did it work, how many failed” is answered uniformly.
