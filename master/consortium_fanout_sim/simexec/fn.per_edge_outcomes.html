Per-edge outcome sequences, ordered by attempt index. Deterministic for a fixed builder config + pipeline inputs ONLY where the attempt-index binding is: the binding is arrival-order-dependent when distinct commands share one edge from unordered tasks (see the module’s determinism contract). Use per_edge_outcome_multisets for the order-independent view; assert_deterministic_equivalence compares multisets for that reason.
