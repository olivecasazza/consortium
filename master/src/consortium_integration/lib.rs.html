1//! # consortium-integration
2//!
3//! The shared contract for consortium's tool integrations (nix, slurm,
4//! ansible, skypilot, ray).
5//!
6//! Integrations all do the same three things: run external commands (locally
7//! or over ssh), read the fleet topology, and report success/failure. This
8//! crate provides each piece once, so integration crates stay thin and —
9//! crucially — testable without real infrastructure:
10//!
11//! - [`exec`] — the [`exec::Executor`] abstraction. Integrations build a
12//!   [`exec::CommandSpec`] and hand it to an executor instead of touching
13//!   [`std::process::Command`] directly. [`exec::ProcessExecutor`] is the
14//!   production implementation (and the only place ssh argv is composed);
15//!   [`exec::ScriptedExecutor`] is the test fake that scripts outputs and
16//!   records invocations.
17//! - [`fleet`] — fleet configuration types ([`fleet::FleetConfig`] and the
18//!   per-integration sub-configs) produced by the Nix library's `mkFleet`.
19//! - [`staging`] — executor-based nix staging helpers
20//!   ([`staging::build_flake_attr`], [`staging::copy_closure`]) used to place
21//!   hermetic environments on remote hosts before running integration
22//!   payloads.
23//! - [`report`] — the [`report::IntegrationReport`] trait every integration's
24//!   report type satisfies.
25//!
26//! # Testing integrations
27//!
28//! ```
29//! use consortium_integration::exec::{CommandSpec, ExecOutput, Executor, ScriptedExecutor};
30//!
31//! // Script the commands your integration is expected to run.
32//! let exec = ScriptedExecutor::new()
33//!     .on("nix build", ExecOutput::ok("/nix/store/abc-env\n"))
34//!     .on_error("sbatch", "socket timed out");
35//!
36//! // ... pass &exec into integration code, then assert on what it did:
37//! # let _ = exec.exec(&CommandSpec::new("nix").args(["build", ".#x"]));
38//! exec.assert_invoked_containing("nix build");
39//! ```
