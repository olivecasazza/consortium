# Documentation

`doc/` is the reference documentation bundle, indexed by
[structure/index.md](index.md). Choose the structure category for repository,
build, and tooling references, usage for operator references, and
architecture for runtime designs.
Each page has one entry in the bundle index.

Rust API documentation is generated by `cargo doc --workspace --no-deps`.
The Docs and Release workflows publish it to GitHub Pages; the Docs workflow
also writes the site's root redirect to `latest/`.
`examples/` holds only runnable code and fixtures. Each usage page's
features are run in CI by a walkthrough script beside the code it exercises;
the commands on the page use placeholder hosts and paths.

The ClusterShell Python documentation is maintained upstream. The upstream
oracle, compatibility bridge, and parity suite belong to consortium-tests.
