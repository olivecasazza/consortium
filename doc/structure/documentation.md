# Documentation

`doc/` is the reference documentation bundle, indexed by
[structure/index.md](index.md). Choose the structure category for repository,
build, and tooling references, and architecture for runtime designs.
Each page has one entry in the bundle index.

Rust API documentation is generated by `cargo doc --workspace --no-deps`.
The Docs and Release workflows publish it to GitHub Pages;
`docs-index/index.html` supplies the version landing page.
Runnable usage examples live beside their Cargo manifest in `examples/`.

The ClusterShell Python documentation is maintained upstream. The upstream
oracle, compatibility bridge, and parity suite belong to consortium-tests.
